# RealtaSkyCam

![The 3D Print](images/The3DPrint.png)

We are a farther and son team, Dad doing the 3d print design Son doing the software side of things.

Project that will enable people to build an all sky camera for checking sky quality or just recording the stars using "off the shelf" components and open source freely available software. Quotes are being used here as some of the hardware is open hardware and not always available in all markets!

The hardware design has been finalised and now we are on to the software build. 

The 3D print is designed such that the camera hardware will be inside the Perspex dome so waterproof by default, the brains i.e. the Raspberry Pi will be housed separately in a case behind a wall...you will need to drill a hole or find some other way to route the cable. We mount it on our detached garage with the cable going through one of the many holes between its roof and walls. 

The software is expected to be run on a raspberry pi and we are reviewing what API/framework to use, no biases other than it should work well on a Pi 3. 

Plan for the next week is.

1) Upload STL's for Camera case and Pi 4 case.
2) Decide on API frame work.
3) Upload STL's for Pi3 and Pi5 cases.

We will be using AI for the software side of things, we are living in the real world and it is a massive productivity multiplier primarily as a really good search for discussing API usage secondary as IDE interface. We will be using Visual studio code and a self hosted LLM mainly as an additional learning opportunity and because we really don't want to spend any money doing this :).
